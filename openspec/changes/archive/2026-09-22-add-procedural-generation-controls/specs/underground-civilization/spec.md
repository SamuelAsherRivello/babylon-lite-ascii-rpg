# Spec Delta

## ADDED Requirements

### Requirement: Selected civilization distribution profile
The Underground civilization pass SHALL apply the selected Civilization density profile to its placement chance while preserving its existing occupancy, terrain-preservation, and realm restrictions.

#### Scenario: High civilization profile remains Underground-only
- **WHEN** a world is generated with High Civilization density
- **THEN** only Underground receives the increased civilization placement chance and Overground receives no civilization features
