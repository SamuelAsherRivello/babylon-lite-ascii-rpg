# Tiny-Swords Tiled Overworld

The project uses a 64x64 Tiled grid. Open `Levels/overworld-tiny-swords.tmx` in Tiled. The Grass layer is filled with a 64px grass tile. The Dirt layer contains one flat ground tile in the upper-left cell. The 64x128 cliff artwork therefore occupies two tiles instead of eight. All PNG sheets in `Terrain/Tilesets` have external `.tsj` definitions.
